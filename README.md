# AI-Based Plagiarism Checker with Paraphrase Detection

## 📌 Description
This project is an AI-powered plagiarism detection system that identifies both exact copying and paraphrased content. It uses TF-IDF for lexical similarity and SBERT for semantic similarity.

## 🚀 Features
- Detects exact and paraphrased plagiarism
- Uses TF-IDF and SBERT models
- Calculates similarity using cosine similarity
- Displays plagiarism percentage

## 🛠 Technologies Used
- Python
- Django
- Scikit-learn
- Sentence Transformers (SBERT)
- HTML, CSS

## ▶️ How to Run
1. Install dependencies using pip install -r requirements.txt
2. Run the server using:
   python manage.py runserver
3. Open browser at http://127.0.0.1:8000/
